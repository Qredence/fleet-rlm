Snapshot image construction uses `build_snapshot_image()` which installs exact-pinned packages from `snapshot-requirements.txt`; the digest of those pins is injected as `FLEET_SNAPSHOT_DEPENDENCIES_SHA256` at build time. The in-memory binding store (`InMemoryBindingStore`) is used by default for kernel smoke tests, while durable mode requires passing a SQLAlchemy `async_sessionmaker` or using `LiveKernelResources.with_sqlite_file(db_path)` to create tables automatically.
