Python async/await with SQLAlchemy `AsyncSession` for binding persistence, the external `daytona` SDK (`AsyncDaytona`, `CreateSandboxFromSnapshotParams`, `SessionExecuteRequest`) for sandbox lifecycle, and a self-hosted Python `http.server` threaded HTTP broker running inside each sandbox on port 3000. Snapshot dependencies are pinned exactly in `snapshot-requirements.txt` and verified via SHA-256 digest.
