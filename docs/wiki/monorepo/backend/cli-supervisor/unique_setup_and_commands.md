Requires Node.js 22.19+ and `pnpm` installed on PATH; the supervisor expects a `tools/fleet-tui` workspace containing `package.json` and `src/cli.ts`. Database migrations must be current — the supervisor calls `scripts/db_init.py` when Alembic head is not met. The `--allow-non-loopback-bind` flag is required to bind to non-loopback addresses because the API has no caller authentication.
