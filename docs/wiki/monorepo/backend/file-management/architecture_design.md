The module is split into three cooperating layers separated by Protocol interfaces:
- Domain models (`models.py`, `workspace_models.py`) define immutable frozen dataclasses (`AttachmentRef`, `StagedAttachment`, `WorkspaceEntry`, etc.) and Protocols (`AsyncByteSource`, `RunAttachmentSink`, `SessionWorkspaceFS`) that decouple callers from storage backends.
- Lifecycle & orchestration (`lifecycle.py`) implements `AttachmentLifecycleService`, which coordinates an `AttachmentCatalog`, `AttachmentBlobGateway`, and `AttachmentPathPolicy` to handle upload, integrity verification (SHA-256), rollback on failure, and Run-scoped staging via a `RunAttachmentSink`.
- Tool hosts (`tools.py`, `workspace_tools.py`) expose synchronous `dspy.Tool` functions (`read_attachment`, `create_artifact`, `publish_workspace_artifact`, `list_workspace_files`, `read/write/append_workspace_text`) over the above abstractions, each with bounded `event_views()` projections for safe telemetry.
- Storage contracts (`volume_storage.py`) define `VolumeBlobFs`, `WorkspaceVolumeGateway`, and `WorkspaceVolumeSession` Protocols so implementations can be filesystem, remote blob store, or in-memory.
- Path safety (`volume_paths.py`, `workspace_validation.py`, `safety.py`) centralizes all path validation: UUID-only tokens, mount-root confinement via `resolve_under_root`, workspace path canonicalization, filename sanitization, and size limits. All host paths are never exposed to clients — only logical `PurePosixPath` values are used internally.
- Error taxonomy (`errors.py`) provides a single `AttachmentError` hierarchy consumed uniformly across layers.
