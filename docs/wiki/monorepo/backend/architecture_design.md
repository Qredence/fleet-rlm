The package is organized as a layered Python module rooted at `src/fleet_rlm/`. `app.py` defines `create_app()` which builds the FastAPI instance, installs error handlers and OpenAPI contracts, mounts all route routers under `api/routes/`, and selects a runtime composition (Daytona or Deno) based on `Settings.run_environment`. The `composition/` package provides pluggable installers (`install_daytona_composition`, `install_deno_composition`) that attach shared state to `app.state` (engine, session factory, turn state store, skill catalog). `main.py` exposes the default ASGI `app` entrypoint. `config.py` centralizes all process configuration through Pydantic `BaseSettings` plus a TOML policy file with strict schema validation; settings flow downward into every child layer. Cross-cutting concerns — `persistence/` (SQLAlchemy ORM + repositories), `observability/` (MLflow tracing + failure diagnostics), `rlm/` (DSPy RLM runner), `chat/` (turn lifecycle), `artifacts/`, `files/`, `sessions/`, `skills/`, `daytona/`, and `api/` — are all wired in at startup through this central factory rather than imported eagerly, keeping each layer isolated until needed.
