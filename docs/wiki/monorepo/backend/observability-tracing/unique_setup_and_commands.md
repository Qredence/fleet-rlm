Tracing is gated by `FLEET_MLFLOW_TRACING_ENABLED` plus required `FLEET_MLFLOW_EXPERIMENT_NAME`, `FLEET_MLFLOW_TRACE_CATALOG`, `FLEET_MLFLOW_TRACE_SCHEMA`, `FLEET_MLFLOW_TRACE_TABLE_PREFIX`, and `FLEET_MLFLOW_TRACING_SQL_WAREHOUSE_ID`. Databricks auth uses standard SDK env vars (`DATABRICKS_HOST`, `DATABRICKS_TOKEN`) which are bridged from Settings' `_dotenv_values` when not already exported.
