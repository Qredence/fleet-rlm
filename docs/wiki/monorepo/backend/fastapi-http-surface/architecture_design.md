The module is a FastAPI application layer organized around per-feature routers under `routes/` (artifacts, attachments, runs, sessions, settings, skills, turns, workspace_files). Each router defines endpoints that consume Pydantic models from `schemas.py` and obtain services through dependency injection in `dependencies.py`, which reads collaborators from `request.app.state` (TurnCoordinator, AttachmentLifecyclePort, ArtifactReaderPort, SessionCatalog, TurnLifecycle, ConfigPolicyService, WorkspaceFileService, Settings) and raises 503 when composition is not ready. Cross-cutting concerns are centralized: `errors.py` installs unified JSON error responses (`ErrorResponse` with `code`/`message`) and normalizes validation errors; `openapi.py` patches the OpenAPI schema to document the closed error contract and the SSE chunk union type; `sse.py` provides `AISDKUIProjector`, a stateful projector mapping internal `RuntimeEvent` variants to AI SDK UI v1 SSE chunks; `ui_message.py` projects committed turn records into the same UIMessage shape for REST pagination; `local_scope.py` supplies deterministic single-user `LocalScope` identity via uuid5-derived constants. Dependency direction is strictly inward: routes → dependencies → domain services; the layer never imports sibling layers beyond these shared helpers.
