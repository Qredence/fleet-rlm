Database initialization uses `create_async_engine_from_url(url)` followed by `create_session_factory(engine)`; production schema evolution goes through Alembic (`alembic.ini` + `migrations/`), while `create_tables()` is explicitly documented as test/dev-only. `check_database_compatibility()` validates that the connected database's `alembic_version` matches every Alembic head before startup.
