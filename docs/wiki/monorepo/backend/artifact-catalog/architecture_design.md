The module is organized around immutable dataclasses in `models.py` (`ArtifactRef`, `ArtifactCandidate`, `ArtifactAccess`, `ArtifactContent`) that carry no host paths. `safety.py` centralizes validation (kind parsing, title sanitization, size limits, JSON encoding) and raises domain errors from `errors.py`. `local_catalog.py` implements `LocalArtifactCatalog`, which persists each artifact as a `.bin` blob and `.meta.json` record under a configurable root, optionally promoting bytes into a `VolumeBlobFs` workspace scope; it also exposes `LocalArtifactReaderCatalog` and `LocalArtifactBlobGateway` adapters. `reader.py` defines the `ArtifactCatalog` and `ArtifactBlobGateway` Protocols plus an `ArtifactReader` that enforces authorized reads and verifies content checksums against `ArtifactRef`. `promotion.py` provides pure policy validation for batches of `ArtifactCandidate`s before durable writes via a `RunArtifactSink` Protocol. `workspace_storage.py` bridges to `WorkspaceVolumeGateway` for reading promoted blobs. Dependency direction flows inward: catalogs and readers depend on models/safety/errors, while promotion is stateless policy; nothing imports back from higher layers.
