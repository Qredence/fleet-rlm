Requires the exact DSPy version `3.3.0b1` — composition fails at import time if `dspy.__version__` differs. Model bundles require both `root` and `sub` LLM roles configured with API keys resolved from environment variables or `.env` via `Settings.llm_role(role).api_key_env`. When using Databricks AI Gateway, `workspace_url` must be supplied and the base path `/ai-gateway/openai/v1` is appended automatically.
