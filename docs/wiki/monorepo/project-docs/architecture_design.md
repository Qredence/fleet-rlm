The module is a flat Markdown documentation tree organized by audience and purpose rather than code modules. Top-level entry points are `index.md` (home), `README.md` (overview/quickstart), and `SUMMARY.md` (table of contents). Reference material lives under `reference/` (configuration, HTTP API, CLI, database, source layout, codebase map). How-to guides are under `how-to-guides/`. Architecture decisions are recorded as ADRs in `adr/`. The `agent-harness/` directory defines the repo-local engineering loop with its own reading path and contract, linking back to `src/fleet_rlm/`, `openapi.yaml`, Alembic migrations, and `make check`. Legacy/internal history is isolated under `internal/legacy-backend/` with its own phased plan directories. Implementation plans live under `superpowers/plans/` and `plan-implementation/`. There is no build system inside this module — it documents the Python FastAPI backend (`src/fleet_rlm/`) and the TUI client (`tools/fleet-tui/`) but contains no executable code.
