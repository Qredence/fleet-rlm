Documentation is consumed through the project's existing tooling: `uv sync --all-extras --dev` to install dependencies, `uv run fleet cli` or `uv run fleet deno` for quickstart, `make api-sync` to regenerate `tools/fleet-tui/src/generated/openapi.ts` from `openapi.yaml`, and `make check` as the normal local gate. Live Daytona/DSPy checks use only canonical `FLEET_*` environment variables.
