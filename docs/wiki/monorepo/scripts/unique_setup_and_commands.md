Scripts are run directly with `uv run python scripts/<script>.py [args]`. `db_init.py` requires `FLEET_DATABASE_URL` (or `--database-url`) and reads `.env` via `python-dotenv`. `openapi_tools.py` requires `pnpm` and `openapi-typescript` installed under `tools/fleet-tui`. `validate_release.py` needs `git ls-files` available and expects built wheels under `dist/`. Many scripts write artifacts into `.data/datasets/` or `openapi.yaml` at the repository root.
