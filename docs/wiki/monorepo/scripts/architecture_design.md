Each script is an independent entry point with its own `argparse` CLI and a `main()` function returning an integer exit code, invoked via `if __name__ == "__main__": raise SystemExit(main())`. There is no shared library layer — cross-cutting concerns are duplicated per script (e.g. `ROOT = Path(__file__).resolve().parents[1]`, YAML/JSON I/O, Alembic invocation). The `benchmarks/` subpackage groups synthetic task generators (`oolong.py`, `sniah.py`) and their scorer (`oolong_scorer.py`) aligned with the OOLONG paper; it is self-contained and does not import the rest of the project except through explicit `sys.path.insert` in scripts like `openapi_tools.py`. Dependency direction is one-way: scripts depend on the installed backend package (`fleet_rlm.main.app`, Alembic, PyYAML, tomllib/tomli) but the backend never imports these scripts.
