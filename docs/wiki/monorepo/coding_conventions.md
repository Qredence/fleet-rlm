- All Python code is formatted with ruff (double quotes, 120-col line length, py311 target) and type-checked with `ty` excluding tests/scripts/notebooks.
- Tests are organized under `tests/unit/backend`, `tests/contracts/backend`, `tests/e2e`, etc., and tagged with pytest markers (`unit`, `integration`, `contracts`, `db`, `e2e`, `benchmark`, `deno`, `live_llm`, `live_daytona`).
- Configuration is loaded via `pydantic-settings` from environment variables defined in `.env.example` and selected by TOML policy profiles referenced through `FLEET_CONFIG_PROFILE`.
- OpenAPI contract lives in `openapi.yaml` and is the single source of truth, regenerated by `scripts/openapi_tools.py` and consumed by both the backend and the TUI client.
- Database schema changes go through Alembic migrations in `migrations/` driven by `alembic.ini`, with conditional SQLite/PostgreSQL indexes.
- Cross-package import boundaries are enforced by `scripts/check_codebase_tree.py` so children cannot violate their declared module graph.
