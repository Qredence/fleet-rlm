`make install` / `make install-dev` / `make install-all` (uv sync with extras); `make dev` boots the FastAPI web app; `make check` runs the full quality gate (lint, format, typecheck, daytona-cov tests, api-check, tui-check, codebase-tree, docs); `make release` performs clean + check + security + build-release; `make api-sync` regenerates OpenAPI and TUI HTTP types; `make cloud-preflight` validates FastAPI Cloud deployment readiness.
