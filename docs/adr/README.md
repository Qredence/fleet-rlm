# Architecture decision records

Architecture decision records capture accepted choices that are costly to
reverse or surprising when reading one module in isolation. Current runtime
behavior remains documented in the architecture and reference guides; an ADR
marked implementation-pending describes the accepted destination until its
cutover lands.
