---
name: report-writing
description: Write a standalone sourced report, decision memo, or Markdown handoff brief from supplied findings for a named audience.
---

Open with the conclusion the reader needs. Use the supplied sources to establish what happened, which decision follows, and which uncertainty matters. If the inputs support a complete brief, write it in this turn.

Put each figure beside its unit, period, and source location. Distinguish an explanation supported by evidence from a possible explanation. When sources disagree, show both values and what would resolve the difference.

Save the requested Markdown file under /workspace/artifacts. Reopen it as a reader: can the audience identify the takeaway, trace each material claim to its source, and see the outstanding question? Correct any mismatch and return the path.
